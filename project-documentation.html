ParkFinder Project Overview

1. Connection Strings & Environment

The system connects via the following defaults in the absence of a .env file (note that the README.md says it's in-memory, but the codebase actually connects to a MySQL database).

MySQL Database Connection (Backend)

  • Host: localhost (env: DB_HOST)
  • User: root (env: DB_USER)
  • Password: root (env: DB_PASSWORD)
  • Database: parkfinder (env: DB_NAME)
  • Connection Limit: 10

JDBC/Connection String equivalent: mysql://root:root@localhost:3306/parkfinder

Frontend to Backend Connection

  • Base URL: http://localhost:5000
  • Axios Instance: Located at frontend/src/api/axios.js

Security & Auth

  • JWT Secret: your_super_secret_jwt_key_123 (env: JWT_SECRET)
  • Token Expiry: 7 days

2. Database Schema (MySQL)

The database consists of three main tables: users, lots, and bookings.

users

ColumnTypeConstraints
idINTPRIMARY KEY, AUTO_INCREMENT
nameVARCHAR(255)NOT NULL
emailVARCHAR(255)NOT NULL, UNIQUE
password_hashVARCHAR(255)NOT NULL
created_atTIMESTAMPDEFAULT CURRENT_TIMESTAMP

lots

ColumnTypeConstraints
idINTPRIMARY KEY, AUTO_INCREMENT
nameVARCHAR(255)NOT NULL
areaVARCHAR(255)NOT NULL
slotsINTNOT NULL
price_per_hourDECIMAL(10, 2)NOT NULL
owner_idINT(Used in provider routes, dynamically inserted)

bookings

ColumnTypeConstraints
idINTPRIMARY KEY, AUTO_INCREMENT
user_idINTFOREIGN KEY references users(id)
lot_idINTFOREIGN KEY references lots(id)
lot_nameVARCHAR(255)NOT NULL
areaVARCHAR(255)NOT NULL
price_per_hourDECIMAL(10, 2)NOT NULL
hoursINTNOT NULL
totalDECIMAL(10, 2)NOT NULL
statusENUM'confirmed' or 'cancelled', DEFAULT 'confirmed'
created_atTIMESTAMPDEFAULT CURRENT_TIMESTAMP

3. Backend API Endpoints

Authentication

  • POST /api/signup - Register a new user
  • POST /api/login - Authenticate and get JWT
  • GET /api/me - Get current user profile

Parking Lots (Public)

  • GET /api/lots - Get all lots (supports ?sort=available|price)
  • GET /api/lots/:id - Get specific lot details
  • GET /api/parkings - Legacy alias for /api/lots

Bookings (Protected)

  • POST /api/bookings - Book a parking slot (decrements slots)
  • GET /api/bookings - View my bookings
  • POST /api/bookings/:id/cancel - Cancel booking (increments slots)
  • PATCH /api/bookings/:id/cancel - Legacy alias for cancellation

Provider / Lot Owner Routes (Protected)

  • POST /api/lots - Create a new parking lot
  • PUT /api/lots/:id - Update lot details
  • DELETE /api/lots/:id - Delete a lot
  • GET /api/provider/lots - View lots owned by current user
  • GET /api/provider/bookings - View all bookings made on owned lots
